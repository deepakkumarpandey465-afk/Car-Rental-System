# Car Rental System 🚗

A Java and MySQL based Car Rental Management System.

## Features

- View available cars
- Rent a car
- Store customer details
- Calculate rental charges
- Save rental details in MySQL
- Show unavailable cars
- Return cars
- Update car availability
- Update rental status to RETURNED
- Print rental receipt

## Technologies Used

- Java
- MySQL
- JDBC
- MySQL Connector/J

## How to Run

1. Install Java.
2. Install MySQL Server and MySQL Workbench.
3. Clone this repository.
4. Create the `car_rental_db` database.
5. Configure your MySQL username and password in `DatabaseConnection.java`.
6. Add MySQL Connector/J.
7. Run `Main.java`.

## Database

The project uses MySQL to store:

- Customer details
- Car details
- Rental details
- Rental status
- Car availability
